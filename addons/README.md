# Pinned AdMob source

The project retains the minimal functional Poing AdMob 5.0.0 GDScript Android addon under `addons/admob/`, copied from the local `squirrel` project. Its upstream `LICENSE` is MIT. Samples, C# support, documentation, iOS support, mediation extras, and source-development folders are excluded. The integration contract is documented in `PROJECT_RULES.md`; production identifiers and consent review remain pending.
