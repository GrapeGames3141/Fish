# Testing Strategy

Run deterministic domain tests for state transitions/timeouts, clockwise reel behavior, tension escape, save round trip, desktop AdMob contract, and project settings. The AdMob seam asserts no native banner request before SDK completion, exactly one afterward, and duplicate completion callbacks are ignored. Haptic tests inject an emitter and assert all six fish signature/cadence pairs are unique, phrases do not accumulate per frame, the hook confirmation precedes the first species phrase, high/red warnings repeat at universal escalating cadences, normal/high/red tier transitions reset correctly, disabling clears pending work, and caught/escaped terminal rhythms differ. Export settings tests assert the arm64-only, compressed-native, signed debug package and critical exclusions. Use capture scenarios `ready`, `armed`, `bite`, `reeling`, `caught`, `escaped`, and `synthetic_reserve` to render 720×1280 evidence.

Physical Android validation is a later gate: verify real sensor thresholds, vibration timing, lifecycle, UMP, native adaptive banner geometry, touch comfort, and performance on a named device. Desktop success does not validate those properties.

Final Gate 1 evidence includes deterministic domain tests, parser import, and a signed APK install record. The installed app was not launched or playtested, so motion, haptics, UMP, real banner geometry, lifecycle, and performance remain unvalidated. The 0.1.0-gate1 signed APK baseline was 92,226,005 bytes; the next 0.1.1-gate1 export must record size, SHA-256, signing, and package inspection to demonstrate the packaging reduction.
