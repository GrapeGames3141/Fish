# Cast & Crank project rules

This repository is the durable source for the Gate 1 vertical slice. Follow `TASK.md` first, then `PROJECT_RULES.md`, then the detailed design documents. Preserve unrelated changes and do not promote generated concept imagery into runtime production art before the documented human gate.

Use `E:` for retained builds, captures, and tool data. For every Godot invocation record exact command, PIDs observed, result, evidence, and cleanup in `reports/godot_process_log.md`. Do not claim device, sensor, haptic, native ad, or human approval without direct evidence.
