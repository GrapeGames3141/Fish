# Art Direction — Gate 1 pending review

The target visual language is sunlit freshwater storybook illustration: deep teal water, sky-blue horizon, warm gold accents, high-contrast cream text, and scenic freshwater plates. Production UI copy is native Godot text. The user authorized the UI v2 Pine Lake/Cedar River plate and six-fish atlas family for this first runtime pass; immediate catches are scenic rather than trophy-mounted, while the decorative journal treatment is reserved for Records. The generated concept board in `concepts/gate1/` remains an approval artifact, not a runtime asset.

UI v2 remains pending human aesthetic approval. Scenic catches use the transparent fish atlas because the catch species is dynamic. Records instead uses the cohesive opaque `records-screen-v02.png` journal master: its static CATCH RECORDS crest, fish, cards, and plaques are author-time composited, while native runtime text supplies changing names/counts/bests and a safe-area-aware back affordance. Prefer opaque authored plates for static framing; add runtime layers only for dynamic, localized, stateful, safe-area, animated, or reusable content, especially where transparency would add no value or create alpha risk. Mockup composition and matte source masters remain provenance-only and are excluded from Android export.
