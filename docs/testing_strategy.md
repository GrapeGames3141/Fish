# Testing Strategy

Run deterministic domain tests for state transitions/timeouts, clockwise reel behavior, tension escape, save round trip, desktop AdMob contract, and project settings. The AdMob seam asserts no native banner request before SDK completion, exactly one afterward, and duplicate completion callbacks are ignored. Haptic tests inject an emitter and assert all six fish signature/cadence pairs are unique, phrases do not accumulate per frame, the hook confirmation precedes the first species phrase, high/red warnings repeat at universal escalating cadences, normal/high/red tier transitions reset correctly, disabling clears pending work, caught/escaped terminal rhythms differ, and Android amplitude maps/clamps to 1–255. Source tests retain the direct AndroidRuntime vibrator contract: API 26+ uses VibrationEffect amplitude while min-SDK API 24–25 uses the legacy duration-only vibrator, with non-Android `Input.vibrate_handheld` fallback. Export settings tests assert the arm64-only, compressed-native, signed debug package, Android `VIBRATE` permission, recursive non-runtime exclusions, and retention of runtime AdMob mediation dependencies. Use capture scenarios `ready`, `armed`, `bite`, `reeling`, `caught`, `escaped`, and `synthetic_reserve` to render 720×1280 evidence.

Physical Android validation is a later gate: verify real sensor thresholds, vibration timing, lifecycle, UMP, native adaptive banner geometry, touch comfort, and performance on a named device. Desktop success does not validate those properties.

Final Gate 1 evidence includes deterministic domain tests, parser import, signed APK inspection, install evidence, and a limited launch trace. The independent v4 domain run passed; the earlier wrapper run failed before loading the project because its space-containing path was unquoted. The final 0.1.3-gate1 arm64 APK is 38,964,971 bytes, SHA-256 `B3823D65C96D502D9F2C70FCB0405D3AC6195F75864465FB7230AA9F64FBAB78`, versionCode 4 / min SDK 24 / target SDK 36, v2 signed with the existing debug certificate. It retains VIBRATE, two HapticService entries, and 10 runtime MediationExtras entries; libgodot is 76,177,376 bytes compressed to 27,833,653 bytes, and audited reports prefixes count 0. The Pixel install succeeded and VIBRATE is granted, but the device remained locked/asleep, so physical haptics, foreground interaction, touch, lifecycle, UMP, real banner geometry, visuals, and performance remain unvalidated.
